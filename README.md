## 📖 项目简介 (About)

本项目整理了**同济大学数据科学与大数据技术**专业相关的课程学习资料、作业代码、实验报告以及综合大作业（期末 Project）。

仓库用于整理和沉淀课程知识体系，也希望能为相关专业学生及对数据科学感兴趣的自学者提供参考思路。

涵盖的领域包括：`计算机基础`、`数据科学`、`机器学习`、`深度学习`、`编程语言`等。
